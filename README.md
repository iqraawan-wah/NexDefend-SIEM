# 🛡️ NexDefend-SIEM - Next-Gen Security Information & Event Management

NexDefend-SIEM is a lightweight, Python-based SIEM solution designed for real-time threat detection, log analysis, and security monitoring for small networks and SOC learning.

### 🚀 Key Features
- **Real-Time Log Monitoring:** Monitors system logs and network events in real-time.
- **Threat Detection Engine:** Detects brute-force, port scanning, and suspicious logins.
- **Alert Dashboard:** Simple and interactive web dashboard (Flask/Streamlit) for alerts.
- **Log Normalization:** Parses and normalizes logs from different sources.
- **Incident Reporting:** Auto-generates alerts with severity levels (Low, Medium, High).

### 🛠️ Tech Stack
- **Language:** Python 3.9+
- **Framework:** Flask / FastAPI
- **Frontend:** HTML, CSS, Bootstrap
- **Logs:** Custom / Syslog / Windows Event Logs
- Smart SEIM Dashboard for threat detection
- Run; python -m streamlit run app.py
